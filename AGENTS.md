# AGENTS.md

Guidance for coding agents (Claude Code and others) working in this repository. This is the ambry.app website (Jekyll, GitHub Pages).

## Content policy

Ambry plays audiobooks the operator owns. Everything this project publishes has to be consistent with that: code, comments, tests, fixtures, docs, screenshots, branch names, commit messages, and PR and issue text.

- How an operator obtains files is outside Ambry, and Ambry has no features for it. Call where files arrive the **source folder**, and don't name file-sharing networks, trackers, download clients or indexers.
- Ambry never integrates with tools that acquire media, and never removes, works around or explains DRM. Name a format by its codec ("E-AC-3 JOC"), never by the store that sold it.
- Examples, fixtures and screenshots use public-domain works. Never use the operator's own library, paths or hostnames.
- No hosted content, no public server directory, no sharing between servers.
